# Security Policy

## Supported versions

Security fixes are made on the latest version published from the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability and do not attach pairing tokens, device cookies, Tunnel tokens, logs, or diagnostic exports.

Use [GitHub Private Vulnerability Reporting](https://github.com/g826796047/Codex-Control/security/advisories/new). If that link is unavailable, the repository owner must enable **Settings → Code security and analysis → Private vulnerability reporting** first.

Include the affected version, reproduction steps, impact, and any suggested mitigation. Please allow a reasonable time for a fix before public disclosure.
